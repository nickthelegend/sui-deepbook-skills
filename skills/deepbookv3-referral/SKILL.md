# DeepBook V3: Referrals

DeepBook V3 includes a built-in referral system. It allows integrators and referrers to earn a portion of the trading fees generated by traders they refer to the platform.

---

## 1. Key Concepts

### Referral Lifecycle
1. **Minting a Referral**: Anyone can mint a `DeepBookPoolReferral` object for a specific pool. The referral is permanently tied to that pool.
2. **Associating a Referral**: A trader associates their `BalanceManager` with the referrer's `DeepBookPoolReferral` ID.
3. **Earning Fees**: When the trader executes **taker orders** in that pool, a portion of the taker fee is redirected to the referrer's accumulated balance. **Maker orders do not generate referral fees**.
4. **Claiming Rewards**: The referrer can claim their accumulated base, quote, and DEEP tokens at any time.

### Multiplier Rules
- The referral multiplier determines the portion of trading fees allocated.
- **Multiple of 0.1**: The multiplier must be a multiple of 0.1 (e.g., 0.1, 0.5, 1.2).
- **Maximum Limit**: The multiplier cannot exceed **2.0**.
- **Upgrades**: Only the owner of the referral object can update its multiplier.

### BalanceManager Mapping
- Associations are pool-specific. A single `BalanceManager` can be associated with different referral IDs for different pools simultaneously.
- Setting a referral requires a `TradeCap` of the balance manager to authorize the association. Any previous referral set for the pool is overwritten.

## 2. On-Chain API (Move)

### Referral Creation & Rewards
- `public fun mint_referral<BaseAsset, QuoteAsset>(pool: &Pool<BaseAsset, QuoteAsset>, multiplier: u64, ctx: &mut TxContext): DeepBookPoolReferral`
  Mints a new referral object with a specified multiplier.
- `public fun update_referral_multiplier(referral: &mut DeepBookPoolReferral, new_multiplier: u64)`
  Updates the multiplier. (Owner only; must be a multiple of 0.1 and $\le 2.0$).
- `public fun claim_referral_rewards<BaseAsset, QuoteAsset>(pool: &mut Pool<BaseAsset, QuoteAsset>, referral: &mut DeepBookPoolReferral, ctx: &mut TxContext): (Coin<BaseAsset>, Coin<QuoteAsset>, Coin<DEEP>)`
  Claims the accumulated referral fees in base, quote, and DEEP tokens. (Owner only).
- `public fun get_referral_balances(referral: &DeepBookPoolReferral): (u64, u64, u64)`
  View current accumulated balances (base, quote, DEEP) without claiming them.

### BalanceManager Operations
- `public fun set_referral(self: &mut BalanceManager, cap: &TradeCap, pool_id: ID, referral_id: ID)`
  Associates a referral ID with the balance manager for a specific pool.
- `public fun unset_referral(self: &mut BalanceManager, cap: &TradeCap, pool_id: ID)`
  Unsets the referral association for a pool.
- `public fun get_referral_id(self: &BalanceManager, pool_id: ID): Option<ID>`
  Reads the currently set referral ID for a pool.

## 3. TS SDK Usage Examples

Using `@mysten/deepbook-v3` to manage referrals:

### Minting a Referral

```typescript
import { Transaction } from '@mysten/sui/transactions';
import { DeepBookClient } from '@mysten/deepbook-v3';

const client = new DeepBookClient(suiClient);

async function mintPoolReferral() {
    const tx = new Transaction();
    
    // Mint referral for SUI/USDC pool with 1.5 multiplier
    const referralId = client.deepbook.mintReferral(tx, {
        poolKey: 'SUI_DBUSDC',
        multiplier: 1.5,
    });
    
    tx.transferObjects([referralId], keypair.toSuiAddress());
    
    await suiClient.signAndExecuteTransaction({
        transaction: tx,
        signer: keypair
    });
}
```

### Associating Referral with BalanceManager

```typescript
async function linkReferral(bmId: string, referralObjectId: string) {
    const tx = new Transaction();
    
    client.deepbook.setReferral(tx, {
        balanceManagerKey: bmId,
        poolKey: 'SUI_DBUSDC',
        referralId: referralObjectId,
    });
    
    await suiClient.signAndExecuteTransaction({
        transaction: tx,
        signer: keypair
    });
}
```

### Claiming Referral Rewards

```typescript
async function claimRewards(referralObjectId: string) {
    const tx = new Transaction();
    
    const [baseCoins, quoteCoins, deepCoins] = client.deepbook.claimReferralRewards(tx, {
        poolKey: 'SUI_DBUSDC',
        referralKey: referralObjectId,
    });
    
    tx.transferObjects([baseCoins, quoteCoins, deepCoins], keypair.toSuiAddress());
    
    await suiClient.signAndExecuteTransaction({
        transaction: tx,
        signer: keypair
    });
}
```

## 4. Events Emitted

- **`DeepBookReferralCreatedEvent`**: Emitted when a referral object is minted.
- **`DeepBookReferralSetEvent`**: Emitted when a referral is set or unset on a `BalanceManager`.
- **`ReferralClaimed`**: Emitted when a referrer claims rewards.
- **`ReferralFeeEvent`**: Emitted on-chain when a taker trade distributes fees to a referrer.
