# DeepBook Margin: Supply Referral System

The supply referral system allows users to earn a portion of the protocol fees generated by liquidity suppliers they refer. When a supplier deposits assets using a referral ID, the referrer earns fees proportional to the interest paid by borrowers over time.

---

## 1. How It Works

The referral system uses a shares-based tracking mechanism:

1. **Create Referral**: Mint a `SupplyReferral` object for a specific margin pool.
2. **Referral ID**: Suppliers provide your referral ID when depositing/supplying liquidity to the pool.
3. **Accumulate Shares**: The referrer's shares in the pool's referral tracker increase proportionally to the supplier's deposited position size.
4. **Earn Fees**: As borrowers pay interest, a percentage goes to protocol fees, and a portion of those protocol fees is distributed to the referrer's claimable fees.
5. **Withdrawal Decrease**: When a referred supplier withdraws their liquidity, the referrer's tracking shares decrease.
6. **Claim Fees**: Referrers can claim and withdraw accumulated fees at any time.

---

## 2. Protocol Fee Distribution Split

The referral spread parameter (configured per margin pool, typically set at 20%) governs referral fee splits.

- **Interest Repaid**: e.g., 100 USDC in interest paid by a borrower.
- **Protocol Spread**: Typically 10% (10 USDC). The remaining 90 USDC goes directly to liquidity suppliers.
- **Fee Distribution Split**:
  - **With Referral (at 20% spread)**:
    - Referrer: 20% of protocol spread (2 USDC)
    - Protocol Treasury: 80% of remaining spread (4 USDC)
    - Pool Maintainer: 25% of protocol spread (2.5 USDC)
  - **Without Referral**:
    - Protocol Treasury: 50% of protocol spread (5 USDC)
    - Pool Maintainer: 50% of protocol spread (5 USDC)

---

## 3. On-Chain API (Move)

Referral features are exposed through the `margin_pool` modules:

- `public fun mint_referral_cap<Asset>(pool: &MarginPool<Asset>, ctx: &mut TxContext): SupplyReferral`
  Mints a new transferable `SupplyReferral` object for a specific margin pool.
- `public fun supply_with_referral<Asset>(pool: &mut MarginPool<Asset>, cap: &SupplierCap, coin: Coin<Asset>, referral_id: ID, ctx: &mut TxContext): u64`
  Supplies assets to the margin pool and links the supplier's position to the referrer's ID. Returns the updated supply shares.
- `public fun claim_referral_fees<Asset>(pool: &mut MarginPool<Asset>, referral: &mut SupplyReferral, ctx: &mut TxContext): Coin<Asset>`
  Withdraws accumulated referral fees. Only the owner of the `SupplyReferral` object can execute this function.
- `public fun query_referral_shares<Asset>(pool: &MarginPool<Asset>, referral_id: ID): (u64, u64)`
  Queries the referral tracker, returning `(shares, unclaimed_fees)` for the specified referral ID.
